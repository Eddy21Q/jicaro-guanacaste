# El legado artesanal del jícaro en Liberia, Guanacaste

Presentación interactiva del segundo avance de Patrimonio Cultural, Universidad de Costa Rica, Sede de Guanacaste.

Abre `index.html` y usa las flechas, los controles inferiores o el menú para recorrer las 17 diapositivas. El audio se reproduce únicamente al solicitarlo.

## GitHub Pages

Repositorio: https://github.com/Eddy21Q/jicaro-guanacaste

Publicación desde la rama `main`, carpeta raíz. No requiere dependencias ni compilación.

La presentación incluye fotografías, cuatro capturas de WhatsApp y el registro de audio. El grupo confirmó que cuenta con consentimiento informado de las participantes para utilizar este material en la presentación académica.

Los archivos multimedia se ubican en `assets/images/` y `assets/audio/`.
